# 🔐 ImadioHide

**ImadioHide** is a cross-media steganography tool that hides secret text inside **images (PNG/JPEG)** and **audio files (WAV)** without visibly altering their quality.

The application supports **encoding and decoding** using secure **LSB (Least Significant Bit)** and **Phase/Parity steganography techniques**, enabling covert communication through digital media with a simple and user-friendly interface.

## ⚙️ Key Features

- 🔒 Hide secret text inside **images and audio files**
- 🧠 Uses **LSB steganography** for image data hiding
- 🎧 Implements **phase/parity technique** for audio steganography
- 📤 Encode secret messages into media files
- 📥 Decode hidden messages from encoded files
- 🧩 Clean and simple web interface
- 🌍 Fully deployed and accessible online
